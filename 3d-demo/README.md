# 시바견 카페 · 동구 — 3D 폰 데모

빌드·설치·CDN 없이 동봉된 Three.js r170으로 실행하는 세로 화면 데모입니다. 기존 루트 게임과 독립적입니다. 사진 속 분홍 다다미, 원목과 대나무 발, 개방창, 벚꽃 정원·분재·석등·자갈·연보라 산을 코드로 재구성했습니다.

## 실행

저장소 루트에서 정적 HTTP 서버를 실행합니다(이미 설치된 Python 사용).

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

PC: `http://localhost:8000/3d-demo/?seed=1`

폰: 같은 Wi-Fi에서 `http://<PC의 LAN IP>:8000/3d-demo/?seed=1`을 엽니다. 방화벽에서 로컬 접속을 허용해야 합니다. `file://`로 열면 브라우저의 ES module 보안 정책 때문에 실패할 수 있습니다. 런타임은 외부 서비스에 접속하지 않습니다.

## 조작과 동작

- 한 손가락/마우스 드래그: 입구 쪽을 중심으로 좌우 ±0.55rad, 피치 0.70~0.88rad로 회전합니다. 기본 피치는 0.78rad이며 앞쪽 툇마루·징검돌·이끼 정원이 화면 하단과 측면으로 이어집니다.
- 두 손가락 핀치/휠: 기본 거리의 0.82~1.18배로 확대·축소합니다.
- 화분·달 조명 탭: 선택 후 초록 바닥 칸을 탭해 이동. 빨간 칸은 이동 불가. 같은 가구 또는 방 밖을 탭하면 취소합니다. 선택 중에는 카메라 조작을 막습니다.
- 테이블은 방석을 포함한 세트입니다. 손님이 입장·대기·퇴장 중인 세트는 이동을 막고 “손님이 앉아 있어요”를 표시합니다. 손님은 2명, 테이블은 3개여서 항상 빈 세트 하나를 직접 옮길 수 있습니다. 퇴장 후 새 손님은 다른 빈 자리로 들어가므로 빈 테이블도 순환합니다.
- 손님은 기존 입구 좌표에 설치한 노렌 문틀을 통해 들어오고 나가며 자기 방석으로 직행합니다. 시바가 옆 칸으로 와서 점프하고 약 4초 동안 손님을 바라보며 앉아 쓰다듬기 장면을 보여 줍니다. 하트는 화면 높이와 깊이에 맞춰 약 18~22 CSS px로 유지하며 2~3개씩 떠올라 개별적으로 사라집니다. 2회 방문받은 손님은 퇴장하고 다른 유형의 손님이 입장합니다.
- 동구는 입구 방석에서 고정된 앉은 자세로 머리와 꼬리만 움직입니다.

10×12, 0.55m 격자와 BFS를 사용합니다. 테이블 2×2칸과 방석 1칸, 화분·조명 각 1칸을 막습니다. 이동은 겹침·범위·입구 통로·자리 접근성·고립된 빈 칸·지나는 캐릭터를 검사하고 경로를 다시 계산합니다.

## 검증

```sh
node --check 3d-demo/main.js
node --check 3d-demo/models.js
node --check 3d-demo/sim.js
node -e "import('./3d-demo/sim.js')"
node 3d-demo/tests/sim.test.mjs
```

7개 테스트: 입장/착석, 방문 2회 후 손님 교체, 1분 순환 및 예약 독점, BFS 막힌 칸 회피, 겹침/범위/입구 거부, 통로 단절 거부/격자 갱신, 빈 테이블 이동/결정성/강제 방문.

390×844 오프라인 헤드리스 검증을 시도했지만 Chrome은 이 작업 환경에서 `setsockopt: Operation not permitted`로 종료되어 화면과 터치를 검증하지 못했습니다. 실기기 60fps는 아직 측정하지 않았습니다. DPR 최대 2, 방향광 1개 그림자(1024), 지오메트리·머티리얼 공유, 정적 배경 InstancedMesh, 하트/대기 표시 재사용으로 부하를 줄였습니다.

## 디버그 / 스크린샷

```js
window.__demo.state();             // JSON 직렬화 가능한 스냅샷
window.__demo.setTimeScale(4);     // 0~20, 0은 정지
window.__demo.forceVisit();        // 즉시 테이블 위 시바 + 쓰다듬기 + 하트
window.__demo.setTimeScale(0);     // 스크린샷 장면 유지
window.__demo.sim;                 // 순수 시뮬레이션
window.__demo.camera;
window.__demo.renderer;
```

`forceVisit()`는 모델 동기화와 렌더까지 즉시 수행합니다. 동일한 `?seed=1`과 동일한 시뮬레이션 시간은 동일한 상태를 만듭니다. 브라우저에서는 고정 1/60초 스텝을 사용하고 백그라운드 복귀 시 누적 시간을 초기화합니다.

## 파일과 출처

- `main.js`: 씬, 카메라, 조명, 터치/Raycaster, 시뮬레이션 동기화, 디버그 훅.
- `models.js`: 코드 생성 모델과 애니메이션, 정적 배경 인스턴싱.
- `sim.js`: DOM/Three 의존 없는 순수 로직.
- `tests/sim.test.mjs`: Node 테스트.
- `vendor/`: 미리 동봉된 Three.js와 MIT LICENSE.
- `package.json`: 로컬 JS를 ES module로 명시(설치/빌드 스크립트 없음).

모든 모델은 직접 코드로 생성했으며 사진/스프라이트 파일은 런타임에 사용하지 않습니다. 자세한 출처는 [CREDITS.md](./CREDITS.md)에 있습니다.
